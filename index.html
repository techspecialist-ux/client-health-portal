Client Account Health Portal

Connect an agency-level GoHighLevel token and list your current clients below. The portal finds those accounts among your agency's sub-accounts and pulls each one's numbers live. Everything else in the agency — test locations, churned clients, internal sub-accounts — is left out.

Export each client's Contacts and Opportunities from GoHighLevel and drop the files here. Nothing is uploaded — the files are read in your browser and the numbers are worked out locally. No API token and no extra permissions needed.

Files are matched to these names automatically where the filename gives it away; otherwise pick the client from the dropdown beside each file.
Drop CSV files here, or click to choose
Contacts and Opportunities exports, any number of clients at once.
Whether a file is contacts or opportunities is worked out from its columns.
Where to find the exports in GHL. Inside a sub-account: Contacts → select all → Export. For deals: Opportunities → Export. Repeat per client. Filenames that contain the firm's name get matched automatically, so renaming them like culpepper-contacts.csv saves you a step.
GHL → Settings → Private Integrations → create a token with read access to Locations, Contacts and Opportunities. An agency OAuth access token works too.
Pre-filled from your connected sub-account. Change it if you manage more than one agency.
Only these accounts are shown. Names are matched loosely — case, punctuation and suffixes like LLP or PC are ignored — and you'll get to review every match before anything is pulled. Once confirmed, the matched location IDs are stored in your saved snapshot so later runs are exact even if a firm gets renamed in GHL.
🔒
Your token is held in memory only. It is never written into this file, never saved to disk, and never sent anywhere except services.leadconnectorhq.com directly from your browser. Closing the tab discards it. Because an agency token can read every client's data, keep this file on your own machine and don't host it publicly.
